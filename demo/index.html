Written the way your reader writes it

Hand it a number and it is written by Intl.NumberFormat. The locale also tells the decimal mark from the grouping marks, so every digit keeps its place value.

Put it on your page

No dependencies and no stylesheet. It respects reduced motion, and screen readers get the plain text.

npm i numeric-text 
import { createNumericText } from 'numeric-text'

const el = document.querySelector('#price')
const price = createNumericText(el)

// Only the digits that changed roll.
price.show('€12.50')

// A number is written by Intl.NumberFormat.
price.show(1299)
<script setup>
import { ref } from 'vue'
import { NumericText } from 'numeric-text/vue'

const players = ref(1259)
</script>

<template>
  <NumericText :value="players" />
  <NumericText :text="`${players} players`" />
</template>
